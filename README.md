# BUAA Computer Architecture

本仓库用于保存北京航空航天大学计算机组成与体系结构相关课程的实验、学习资料和阶段性成果，覆盖 Logisim、Verilog HDL、汇编语言、CPU 设计、流水线和 MIPS 微系统等内容。
